# Shelf: maintainer handover

Everything needed to understand, change, build and ship Shelf. For using the app, see
[USER_GUIDE.md](USER_GUIDE.md); for installing it on other Macs, see [INSTALL.md](INSTALL.md).

## What it is

A native macOS clipboard manager built in October 2026 to replace Paste (pasteapp.io), whose history
synced to iCloud and required a subscription. Goals: local only, light, keyboard first, Apple-native look
(flat, no shadows or badges).

- Swift 5 language mode, SwiftUI + AppKit, Swift Package Manager. No third-party dependencies.
- Builds with Apple's Command Line Tools; full Xcode is not needed.
- macOS 14+, universal binary (arm64 + x86_64).
- Menu bar app (`LSUIElement`), no Dock icon. Bundle id `com.turkifaisal.shelf`.

## How it works

**Capture (Monitor.swift).** macOS has no clipboard-change notification, so a timer checks
`NSPasteboard.general.changeCount` every 0.4 s. On a change it reads, in this order of priority:
file URLs, then text (plus RTF / HTML / flat RTFD for formatted paste, up to 10 MB each), then images
(stored as PNG). Copies marked `org.nspasteboard.TransientType` or `AutoGeneratedType` are skipped.
Shelf's own writes are skipped via `markOwnChange()`. The frontmost app is recorded as the source.
Each capture gets a SHA-256 hash; copying the same content again moves the existing card to the front.

**The shelf (App.swift, ShelfView.swift).** Two borderless `NSPanel`s with `.nonactivatingPanel`: the
shelf at the bottom of the screen and the preview above it. Non-activating means the app you were in
stays frontmost, so the paste lands there. Keys are handled in one local `NSEvent` monitor
(`handleKey` / `handleEditorKey`) using physical key codes, so shortcuts work in any keyboard layout
(including Arabic). The panels hide when focus leaves both of them.

**Pasting.** The item is written to the pasteboard, the panel hides, and a synthetic ⌘V is posted
with `CGEvent` (tagged with `eventSourceUserData` so the paste stack can tell it from a real ⌘V).
Posting key events requires **Accessibility** permission. Without it, the item is still on the
clipboard and the user can press ⌘V.

**Paste stack.** Stacked items are pasted one per ⌘V: Shelf pastes the first, then a global
key-down monitor watches for the user's ⌘V and, 0.2 s later, puts the next item on the clipboard.

**OCR (OCR.swift).** New images are queued; `VNRecognizeTextRequest` runs on a background queue
(English and Arabic where supported). Results go into `items.ocr` and are searched like text.
An empty string means "processed, no text", so images are not retried.

**Shortcut (HotKey.swift).** Carbon `RegisterEventHotKey`, which does not need Accessibility.
Configurable via `defaults write com.turkifaisal.shelf hotkey "cmd+shift+v"`.

## Data

All in `~/Library/Application Support/Shelf/` (folder mode 700, database mode 600):

```
history.sqlite   SQLite (WAL mode)
images/          <sha256>.png, one per image card
Backups/         pinboards-YYYY-MM-DD.json, last 7 kept
```

Schema (`PRAGMA user_version = 2`):

| Table | Columns |
|---|---|
| `items` | `id`, `kind` (text/link/image/file), `text` (content, or newline-separated paths), `image` (PNG filename), `detail` (e.g. "1920 × 1080"), `hash` (unique), `source_bundle`, `source_name`, `created` (Unix time; last copied or pasted), `pinned` (0/1, kept in step with `board`), `board` (pinboard id or NULL), `ocr` |
| `formats` | `item_id`, `type` (pasteboard UTI), `data` (blob) — rich-text representations |
| `boards` | `id`, `name`, `position` |

Rules:
- Unpinned items older than 30 days are deleted at launch and hourly (`Store.prune`), with their images.
- Deleting a pinboard moves its items to History with a fresh 30 days.
- Migrations live in `Store.migrate()`, gated on `user_version`. Add a new `if version < N` step;
  never edit an existing one.

**Never move this folder into the Knowledge Base.** The KB auto-commits to git, and the history
contains passwords and other secrets.

## Build, run, release

```sh
./build.sh             # build universal app into build/Shelf.app
./build.sh --install   # build, install to ~/Applications, relaunch
./build.sh --package   # build and zip to dist/Shelf-<version>.zip (+ INSTALL.md, USER_GUIDE.md) for sharing
swift scripts/make_icon.swift   # regenerate Resources/AppIcon.icns after changing the icon
swift test                      # unit tests (each uses a temp folder, never your real history)
```

`build/`, `.build/` and `dist/` are git-ignored.

**Releasing a new version:**
1. Bump `CFBundleShortVersionString` (and `CFBundleVersion`) in `Info.plist`.
2. `./build.sh --install` and check the change works on your Mac.
3. Commit the version bump and push to `main`.
4. `scripts/release.sh` — builds and packages the signed universal app, notarizes it (Developer ID
   builds), tags `v<version>`, pushes the tag, and creates the GitHub release with the zip,
   INSTALL.md and USER_GUIDE.md attached. The release notes start with this version's CHANGELOG
   section. Requires `gh` authenticated as a maintainer.

Run releases from the maintainer's Mac: it holds the signing identity and the notarization
credentials. CI (`.github/workflows/ci.yml`) only tests and build-checks pull requests; it has no
signing key and does not publish releases. For a local zip without publishing,
`./build.sh --package` still writes `dist/Shelf-<version>.zip`.

### Code signing

`build.sh` picks the first available identity:

1. **Developer ID** — `SHELF_SIGN_IDENTITY`, or the first `Developer ID Application: …` identity in the
   keychain (currently `Developer ID Application: Turki almutairi (C66782F7SB)`). Signed with the
   hardened runtime; `--package` adds a secure timestamp, which notarization requires.
2. **Shelf Local Signing** — a self-signed certificate, for Macs without the Developer ID (see
   "Recreating the Shelf Local Signing certificate" below). Not trusted by Apple, so copies shared from it need
   **Open Anyway**.
3. **Ad-hoc** — works, but macOS asks for Accessibility again after every rebuild.

macOS ties the Accessibility permission to the signing identity, so keep using the same one. Changing
identity (for example Shelf Local Signing → Developer ID in 1.3.0) means every Mac grants Accessibility
once more.

**Notarization.** When the build is signed with a Developer ID, `release.sh` submits the zip to Apple
with the notarytool profile `SHELF_NOTARY_PROFILE` (default `shelf-notary`), stops if Apple doesn't
accept it, staples the ticket to the app, re-zips it and checks it with `spctl`. One-time setup on a
new Mac:

1. Xcode → Settings → Accounts → (team) → Manage Certificates → **+** → **Developer ID Application**.
   Only the team's Account Holder can create it; `security find-identity -v -p codesigning` lists it.
2. Create an app-specific password at account.apple.com → Sign-In and Security, then:
   ```sh
   xcrun notarytool store-credentials shelf-notary --apple-id <apple-id> --team-id C66782F7SB
   ```

Keep the Developer ID certificate's private key private and backed up (Keychain Access → export as
`.p12`, store it in a password manager); anyone holding it can sign apps as you.
If macOS asks whether `codesign` may use a key, choose **Always Allow**.

## Troubleshooting

| Symptom | Cause and fix |
|---|---|
| Accessibility prompt on every paste although Shelf is enabled | The permission entry belongs to an old signature. Run `tccutil reset Accessibility com.turkifaisal.shelf`, then paste once and allow it. |
| ⇧⌘V does nothing | Another app registered it first (Paste does). Quit that app, then relaunch Shelf. |
| `security import` fails with "MAC verification failed" | Homebrew OpenSSL 3 creates PKCS#12 files the keychain can't read. Add `-legacy` to `openssl pkcs12 -export`. |
| Build hangs at `codesign` | A keychain prompt is waiting on screen. Choose **Always Allow**. |
| Searching a fresh screenshot finds nothing | OCR runs in the background; give it a few seconds. |

Recreating the Shelf Local Signing certificate (only for Macs without the Developer ID):

```sh
T=$(mktemp -d) && cd "$T"
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 3650 -nodes \
  -subj "/CN=Shelf Local Signing" -addext "extendedKeyUsage=critical,codeSigning" \
  -addext "keyUsage=critical,digitalSignature" -addext "basicConstraints=critical,CA:false"
openssl pkcs12 -export -legacy -inkey key.pem -in cert.pem -out shelf.p12 -passout pass:temp
security import shelf.p12 -k ~/Library/Keychains/login.keychain-db -P temp -T /usr/bin/codesign
cd / && rm -rf "$T"
```

A new certificate is a new identity: every Mac has to grant Accessibility once more.

## Known limitations

- Only standard rich text (RTF, HTML, RTFD) is kept. App-specific formats (Word styles, Excel cell
  formulas) are not, so a few details may not carry over.
- Text over 2 million characters and formats over 10 MB are not recorded.
- History is not backed up (pinboards are).
- No ignore list: every app's copies are recorded unless capture is paused.
